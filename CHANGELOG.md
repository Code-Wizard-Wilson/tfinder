# Changelog

## Unreleased — 2026-09-30

- Added complete app removal with a preflighted list and sizes for matched application support, cache, preference, saved-state, HTTP storage, WebKit, log, container, application-script, and user LaunchAgent items.
- Added read-only slow-network diagnostics covering DNS latency, Wi-Fi state, default routing, gateway and internet packet loss, active VPN/proxy configuration, and listening TCP ports.
- Added safe Finder fallback for permission-protected application bundles and deterministic multi-app removal phrasing.

## 0.6.0 — 2026-09-28

- Added natural PID inspection, Git questions, recursive project-file search, browser discovery, and slow-Mac diagnostics.
- Expanded the permanent black-box catalog to 7,192 unique user scenarios across all 40 typed actions.
- Added conversational prefixes, numbered input, common Russian typos, mixed-language requests, and more natural system questions.
- Added a one-command installer with an optional private Laya-MLX runtime.
- Added `tf model` as an intuitive alias for daemon controls and made stopped status non-erroring.
- Improved first-run help, installation diagnostics, release metadata, and public documentation.
- Preserved the safety boundary: no model-generated shell, no arbitrary command execution, typed targets, bounded scans, and confirmation for mutations.

## 0.5.3 — 2026-09-27

- Added bounded recursive file search and natural terminal regression coverage.
- Fixed process-by-PID queries being confused with port lookup.
- Added natural Git status/history/branch questions and richer process diagnostics.

## 0.5.2 — 2026-09-26

- Added bounded, body-free HTTP/HTTPS GET requests.
- Added flexible Bluetooth, AirDrop, and Stage Manager wording.

## 0.5.0 — 2026-09-26

- Made natural language the default interface.
- Added local multilingual semantic fallback constrained to the typed action registry.
